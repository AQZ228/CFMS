# コーディング規約

CFMSのコーディングを行う際は以下のコーディング規約に従ってください。
コーディングを行う際には[`CommentAnchor`](https://marketplace.visualstudio.com/items?itemName=ExodiusStudios.comment-anchors)を使用して、コードの説明をコメントとして残すことを推奨します。

## 1. 命名規則

- 変数名はキャメルケースを使用します。(例: `userName`, `totalAmount`)
- クラス名はパスカルケースを使用します。(例: `UserProfile`, `OrderManager`)
- 定数は全て大文字で、単語の区切りにアンダースコアを使用します。(例: `MAX_USERS`, `DEFAULT_TIMEOUT`)
- メソッド名はキャメルケースを使用します。(例: `calculateTotal`, `fetchUserData`)
- ファイル名は小文字のスネークケースを使用します。(例: `user_profile.py`, `order_manager.html`)

<details>
<summary>form送信時のJavaScript</summary>

```javascript
/**
 * サーバーからのレスポンスを表示する関数
 * @param {Object} data - サーバーからのレスポンスデータ
 */
function renderResult(data) {
    const resultDiv = document.getElementById('result');
    if (data.success) {
        resultDiv.innerHTML = `<div class="alert alert-success">${data.message}</div>`;
        console.log('サーバーからのデータ:', data.data);
    } else {
        resultDiv.innerHTML = `<div class="alert alert-danger">${data.message}</div>`;
    }
}

/**
 * フォーム送信時の処理
 */
document.getElementById('sampleForm').addEventListener('submit', function(event) { // id:sampleFormのformを送信する際の処理
    event.preventDefault(); // フォームのデフォルトの送信を防ぐ

    const input = document.getElementById('inputField').value; // id:inputFieldの値を取得

    fetch('<?= getenv('API_URL') ?>/template/template.php', { // 送信先のAPIのURLを指定
            method: 'POST', // api側のメソッドに合わせて変更してください。
            credentials: 'include', // csrf_tokenを送信するために必要です。
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({
                inputField: input, // 受け取り側の変数名に合わせて変更してください。受け取り側名: 変数名
                csrf_token
            })
        })
        .then(response => response.json())
        .then(data => renderResult(data)) // renderResult関数を使用して結果を表示
        .catch(error => {
            console.error('Error:', error);
        });
});
```

$rawData = file_get_contents('php://input');
$data = json_decode($rawData, true);

if ($data === null) {

        "success" => false,

        "data" => []
    ]);
    exit;

//!SECTION

} catch (\Exception $e) {
